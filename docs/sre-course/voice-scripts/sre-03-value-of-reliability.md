> ⟪board B2 step 1⟫ နောက်ထပ် ပျက်နိုင်တဲ့ နေရာတွေထဲမှာ မသီရိ အစိုးရိမ်ဆုံးက SMS code ပို့တဲ့ integration အဟောင်းပါ။ ဒါကို 2 နှစ်လောက် ဘယ်သူမှ မထိ၊ မထိန်းသိမ်းဘဲ ထားခဲ့ပေမဲ့ အဲဒီအတွင်း SMS partner က API ကို ပြောင်းသွားပြီး library တွေမှာလည်း version အသစ်တွေ ထွက်လာပါတယ်။
> ⟪board B2 step 2⟫ ဒီတော့ SMS စာသား တစ်ကြောင်း ပြင်ဖို့တောင် library တွေကို အရင် update လုပ်ရလို့ ပြင်စရာ အသေးလေးက project ဖြစ်သွားပြီး၊ ပြင်လိုက်တိုင်း တခြားနေရာတွေက မထင်ထားဘဲ ပျက်လာပါတယ်။

> ထွက်ပေါက်ကတော့ SMS code ဘယ်လောက် မြန်မြန် ရောက်ရမလဲ ဆိုတဲ့ ပစ်မှတ်ကို သဘောတူထားပြီး ဆွေးမြေ့တာကို အဲဒီ ပစ်မှတ်နဲ့ တိုင်းဖို့နဲ့၊ လက်နဲ့ ထပ်ခါထပ်ခါ လုပ်ရပြီး ရေရှည် တန်ဖိုး မကျန်တဲ့ toil ကို လျှော့ဖို့ပါ။

## Scene 5 · Why 100% is the wrong goal

chapter: 100% က ဘာလို့ မှားလဲ

> ⟪close board⟫ ⟪page l03_p02⟫ ဒါတွေ မြင်တော့ ကိုနေလင်းက ဘယ်တော့မှ မပျက်အောင် 100 ရာခိုင်နှုန်း လုပ်ကြမယ်လို့ ပြောပါတယ်။ ဒါပေမဲ့ 100 ရာခိုင်နှုန်းက မှားတဲ့ ပစ်မှတ်ပါ။ ပထမ အကြောင်းက nine တစ်လုံး တိုးတိုင်း ကုန်ကျစရိတ် အများကြီး တက်တာပါ။ 99.9 ရာခိုင်နှုန်း၊ nine သုံးလုံးကနေ nine လေးလုံးကို တက်ဖို့ဆိုရင် server၊ လူနဲ့ စစ်ဆေးမှုတွေ အများကြီး ပိုလိုပြီး feature ထုတ်တာလည်း နှေးသွားပါတယ်။
> ဒုတိယ အကြောင်းက user က ဘာကွာလဲ မသိနိုင်တာပါ။ လိုင်း အားနည်းတဲ့ user ဆိုရင် သူ့ဖုန်းလိုင်းက ကိုယ့် service ထက် အများကြီး ပိုပြတ်နေတော့၊ ကိုယ်က 99.99 ရာခိုင်နှုန်း ဖြစ်ဖြစ် 100 ရာခိုင်နှုန်း ဖြစ်ဖြစ် သူ့အတွက် မထူးပါဘူး။
> ဒါကြောင့် ပထမဆုံး မေးရမှာက ဒီ service အတွက် reliability ဘယ်လောက် လိုလဲ ဆိုတာပါ။ အဖြေက ပျက်ရင် ဘယ်လောက် ကုန်ကျလဲ ဆိုတာကနေ လာပြီး၊ ကုမ္ပဏီ ကြီးလာရင် ပြောင်းတတ်သလို တခြား ကုမ္ပဏီဆီက ကူးလို့လည်း မရပါဘူး။ ဒီလို သဘောတူထားတဲ့ ပစ်မှတ်ကို service level objective၊ အတိုကောက် SLO လို့ ခေါ်ပါတယ်။
> ပစ်မှတ်နဲ့ 100 ရာခိုင်နှုန်းကြားက ကွာဟချက်ကတော့ error budget ပါ၊ SLO က ခွင့်ပြုထားတဲ့ ပျက်ခွင့်ပါ။ lesson 1 က ကြိုသဘောတူထားတဲ့ risk အကန့်အသတ်ကို ဒီ နာမည်တွေနဲ့ ခေါ်တာပါ။ budget ကျန်သေးရင် feature ဆက်ထုတ်ပြီး ကုန်သွားရင် အရင်ပြင်ရတာကို lesson 6 မှာ လေ့လာပါမယ်။

On screen:

- l03_p02 (K2): 100% က ဘာလို့ မှားလဲ | nine တစ်လုံး တိုးတိုင်း ကုန်ကျစရိတ် အများကြီး တက် | လိုင်း အားနည်းတဲ့ user က ဘာကွာလဲ မသိ | ပစ်မှတ် ရွေး၊ ကွာဟချက်က error budget
