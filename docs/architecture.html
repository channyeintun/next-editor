Notes

01React 19 + Compiler — app shell; compiler auto-memoizes, no manual useCallback/useMemo.
02Monaco editor — the code editing surface.
03Excalidraw — whiteboard; records element upserts/removals as deltas, not full snapshots.
04xstate + store-react — recorder state machine plus lightweight app-level stores.
05WebContainer — boots an isolated Node dev server entirely in the browser.
06Sandboxed iframe — runs the live preview; host and preview talk over postMessage.
07rrweb recorder — captures DOM/input; takes corrective full snapshots when mutations drift.
08dmp + fflate — Rust-to-WASM diff-match-patch codec, deflate-compressed, packed into the SCR3 stream format.
09xterm.js — terminal emulator for the WebContainer shell.
10Hono API routes — lessons, playlists, authors, search, auth, uploads.
11Static assets — Cloudflare Static Assets binding serves the built client.
12/api/proxy — fetch proxy for the preview; blocks loopback/private hosts.
13Google OAuth 2.0 — sign-in; edge issues its own session cookie afterward.
14D1 — SQLite at the edge; relational data for accounts and content.
15R2 — object storage for editor state and recorded media, up to 200MB/upload.
16Upstash Redis — read-through cache; app degrades gracefully if unset.
